Worldwide multiplayer setup

This design is intended for a trusted group of four. The Euchre HTML stays on each player’s computer and talks directly to Firebase Realtime Database over HTTPS. No web server is required for the HTML page.

Important: the Firebase Web API Key and Database URL are client configuration, not secret credentials. The long Table Access Key is used as an unguessable game-room path. Anyone who receives both the Connection Profile and Table Access Key should be treated as a trusted participant. Players can also inspect the game data, so this prototype is not anti-cheat.

Project owner · one-time Firebase setup

  1. Sign into Firebase Console with the Google account that will own the Euchre service and create a Firebase project on the free Spark plan.
  2. Create a Realtime Database. Keep the Database URL shown by Firebase; it normally ends in firebaseio.com or firebasedatabase.app.
  3. Open Authentication and enable the Anonymous sign-in provider. Each browser then gets a temporary Firebase identity without asking the Euchre player to create an account.
  4. In Realtime Database Rules, use the rules below. They deny database-wide browsing but allow an authenticated browser to access a specific game path when it already knows that game’s Table Access Key.
{ "rules": { ".read": false, ".write": false, "games": { "$table": { ".read": "auth != null", ".write": "auth != null" } } } }
  1. In Firebase Project settings, copy the project’s Web API Key. Back on this page, click Build Connection Profile, enter the Database URL and Web API Key, and click Build Connection Profile inside the dialog.
  2. Click Generate key to make a long random Table Access Key. Enter your player name, open Host a new table to enter your partner and the two opposing players, click Connect Firebase. If the Table Access Key is unused and the Host roster is complete, TGWE creates the table automatically.

What to share with the other three players

Share manually:
1. This HTML file (or let them use the GitHub Pages version)
2. The Firebase Connection Profile
3. The Table Access Key
4. The exact player name assigned to them

They double-click the HTML, enter their name, paste the Connection Profile and Table Access Key, click Connect Firebase. TGWE finds the existing table and joins their assigned seat automatically. They never need your Google account password.

If someone wants their own independent Euchre service

They create their own Google account if desired, create their own Firebase Spark project, enable Realtime Database + Anonymous Authentication, install the same rules, and generate their own Connection Profile and Table Access Keys. The downloaded HTML contains no hard-coded dependency on your Firebase project.

Security model

Firebase Security Rules are enforced on Firebase’s servers. This prototype requires an authenticated Firebase session, but anonymous authentication by itself is not strong identity. The unguessable Table Access Key acts as a capability-style invitation for a trusted game. Do not use this architecture for sensitive data, money, rankings, or adversarial play.
